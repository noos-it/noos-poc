# Decisions

One file per decision, `<decision date>-<tool>.md`. Written by the adoption process; see the
repository README for how a request gets here.

A record is not edited after the fact. If a decision changes, that is a new decision and a new
record — the old one stays, because the point of the record is what was known and decided **then**.
Conditions attached to an adoption live in its record; marking them done belongs wherever the work
was tracked, not here.
