# Decisions

One file per decision, named for the decision's identifier — `20261010-linear-7b248dd7b188.md`, whose
last twelve characters tie it back to the workflow run that produced it. Written by the adoption
process; see the repository README for how a request gets here.

Each arrives as its own pull request on a branch named `decision/<identifier>`. Updating the table
below is part of reviewing that pull request.

A record is not edited after the fact. If a decision changes, that is a new decision and a new
record — the old one stays, because the point of the record is what was known and decided **then**.
Conditions attached to an adoption live in its record; marking them done belongs wherever the work
was tracked, not here.
